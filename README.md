# Task Management Backend

This is the backend of the Task Management application. It provides the necessary APIs to manage tasks, users, and authentication. The application is built with Node.js, Express, and MongoDB.

## Features

- **User Authentication:** Register and login functionality with JWT-based authentication.
- **Task Management:** Create, read, update, and delete tasks.
- **Task Status:** Change the status of tasks (e.g., Pending, In Progress, Completed).
- **Pagination:** Supports pagination for task listing.

## Technologies Used

- Node.js
- Express.js
- MongoDB
- JWT (JSON Web Tokens) for authentication
- Mongoose for MongoDB object modeling
- dotenv for environment variable management
- Bcrypt.js for hashing passwords
- CORS for handling cross-origin requests
